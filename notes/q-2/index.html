다중 기질 적응형 지능 시스템 개념 명세

2026년 9월 17일

  1. 목적

현대 AI 시스템의 학습과 자기개선을 하나의 통합된 관점에서 설명한다.

기존에는 다음 영역들이 서로 별개의 분야처럼 다뤄지는 경우가 많았다.

  • 가중치 학습
  • 계속학습
  • 메모리
  • 스캐폴드 개선
  • 월드모델
  • 메타러닝
  • Learned Optimizer
  • Self-Evolving Agent
  • Recursive Self-Improvement, RSI

그러나 시스템 수준에서 보면 이들은 모두 다음 공통 구조의 변형으로 볼 수 있다.

«경험이 시스템의 어떤 지속적 상태를 변화시키고, 그 변화가 이후 행동과 이후 학습에 영향을 준다.»

따라서 핵심 질문은 단순히 "모델이 학습하는가"가 아니다.

보다 일반적인 질문은 다음과 같다.

«무엇이 상태로 지속되는가. 어느 상태가 어떤 시간척도에서 변하는가. 무엇이 그 상태를 업데이트하는가. 어떤 업데이트 규칙이 다시 개선 대상이 될 수 있는가.»

  1. 기본 시스템 상태

적응형 AI 시스템의 상태를 다음과 같이 추상화한다.

[ X_t = (h_t,\theta_t,S_t,W_t,U_t,A_t) ]

각 요소는 다음과 같다.

2.1. "h_t": 빠른 내부 상태

현재 interaction에 따라 빠르게 변하는 neural 또는 latent state이다.

예:

  • recurrent hidden state
  • working state
  • belief state
  • 현재 상황에 대한 latent representation
  • 현재 task state

일반적으로 다음과 같이 갱신될 수 있다.

[ h_{t+1}=F_{\theta_t}(h_t,o_{t+1},a_t) ]

이는 수 초 이하의 빠른 시간척도에서 변할 수 있다.

2.2. "θ_t": 가중치 상태

모델의 parameter에 저장되는 장기적 학습 상태이다.

예:

  • pretraining
  • fine-tuning
  • reinforcement learning
  • continual learning
  • test-time training
  • online weight adaptation

일반적인 형태는 다음과 같다.

[ \theta_{t+1}=U_\theta(\theta_t,E_t) ]

전통적인 머신러닝은 주로 이 층을 "learning"이라고 불러왔다.

2.3. "S_t": 스캐폴드 상태

모델 외부에 존재하지만 시스템 행동을 지속적으로 결정하는 구조이다.

예:

  • persistent memory
  • system prompt
  • skill library
  • tool configuration
  • workflow
  • planner
  • search policy
  • evaluator
  • agent code
  • archive
  • orchestration policy

일반적인 형태는 다음과 같다.

[ S_{t+1}=U_S(S_t,E_t) ]

경험에 따라 스캐폴드가 변하고 그 변화가 이후 행동에 영향을 준다면, 기능적으로 이것 역시 학습으로 볼 수 있다.

이를 가중치 학습과 구별하여 scaffold learning이라고 부를 수 있다.

  1. 학습의 일반화

가중치 학습과 스캐폴드 학습의 공통 구조는 다음과 같다.

experience ↓ persistent state change ↓ future behavior change

따라서 학습을 반드시 parameter update와 동일시할 필요는 없다.

가중치 학습

[ \theta_t \rightarrow \theta_{t+1} ]

스캐폴드 학습

[ S_t \rightarrow S_{t+1} ]

내부 상태 적응

[ h_t \rightarrow h_{t+1} ]

시스템 수준에서는 모두 서로 다른 substrate에서 발생하는 adaptation이다.

따라서 보다 일반적으로는 다음과 같이 표현할 수 있다.

[ (h_t,\theta_t,S_t) \rightarrow (h_{t+1},\theta_{t+1},S_{t+1}) ]

  1. 학습과 개선의 용어 차이

현재 연구문헌에서는 유사한 구조가 substrate에 따라 서로 다른 이름으로 불리는 경향이 있다.

가중치가 바뀌면 보통 다음 표현을 쓴다.

  • learning
  • training
  • adaptation
  • continual learning

스캐폴드가 바뀌면 다음 표현을 자주 쓴다.

  • improvement
  • optimization
  • evolution
  • self-modification
  • agent adaptation

그러나 시스템 수준에서는 두 경우 모두 경험으로 인한 지속적 상태 변화이다.

다만 "improvement"는 "learning"보다 넓은 개념이다.

사람이 직접 코드를 고쳐 성능이 좋아지는 것도 improvement이다.

반면 시스템이 경험을 이용하여 자신의 persistent state를 스스로 갱신한다면 learning이라고 부를 근거가 강하다.

  1. World Model

World model은 별도의 저장 substrate가 아니라 기능적 역할이다.

핵심은 현재 세계 상태와 행동으로부터 미래 상태 또는 결과를 모델링하는 것이다.

예:

[ p(s_{t+1},r_t \mid s_t,a_t) ]

또는

[ (z_t,a_t)\rightarrow\hat z_{t+1} ]

따라서 다음을 구별해야 한다.

Stateful System

과거의 결과가 persistent state로 유지되어 미래 computation에 영향을 준다.

World Model

환경의 상태, 구조, dynamics 또는 counterfactual transition을 표현한다.

두 개념은 동일하지 않다.

World model은 neural state, weights, scaffold 또는 이들의 조합으로 구현될 수 있다.

  1. Stateful Neural Model

특히 중요한 경우는 neural network가 빠르게 변하는 내부 state를 직접 유지하는 경우이다.

[ h_{t+1}=F_\theta(h_t,o_{t+1},a_t) ]

이 경우 "h_t"는 단순한 외부 memory가 아니라 neural computation 내부에서 지속되는 현재 상태이다.

이것은 다음과 같은 역할을 가질 수 있다.

  • 현재 세계 상태
  • belief state
  • task state
  • working state
  • latent world state

JEPA류와 world-model 계열은 세계 상태를 latent representation으로 직접 다룬다는 점에서 이 방향과 가깝다.

다만 world state를 neural representation으로 표현하는 것과, 그 neural state가 interaction 사이에서 자동으로 persistent하게 유지되는 것은 별개의 문제이다.

  1. 다중 시간척도 학습

서로 다른 substrate는 서로 다른 시간척도에서 변화할 수 있다.

대략적인 예는 다음과 같다.

빠른 시간척도

"h_t"

  • 현재 상황
  • working state
  • attention
  • belief state

중간 시간척도

"S_t"

  • memory
  • workflow
  • search policy
  • prompt
  • tool configuration
  • explicit strategy

느린 시간척도

"θ_t"

  • 장기적 내재화
  • representation learning
  • generalized skill
  • consolidated knowledge

따라서 미래 AI 시스템은 하나의 학습 메커니즘보다 여러 시간척도에서 동시에 작동하는 multi-timescale learning system으로 보는 것이 자연스럽다.

  1. 업데이트 규칙

각 substrate를 어떻게 바꿀지는 별도의 update machinery가 결정한다.

[ U_t=(U_h,U_\theta,U_S,\ldots) ]

예:

  • "U_h": 현재 내부 state 갱신
  • "U_θ": optimizer, RL rule, training procedure
  • "U_S": memory update, policy rewrite, code modification

전통적으로는 "U"가 시스템 외부에서 사람이 설계한 고정된 규칙인 경우가 많았다.

  1. 메타러닝

업데이트 규칙 자체가 학습 대상이 되면 meta-learning이 시작된다.

예:

[ \theta_{t+1}=U_t(\theta_t,E_t) ]

그리고

[ U_{t+1}=M(U_t,E_t) ]

이 경우 시스템은 단순히 task를 학습하는 것이 아니라, task를 학습하는 방법도 학습한다.

계층적으로 보면 다음과 같다.

Level 0 행동 또는 출력 생성

Level 1 가중치·상태·스캐폴드 학습

Level 2 학습 규칙 학습

Level 3 학습 규칙을 개선하는 규칙 학습

Level 4 그 상위 규칙의 개선

형식적으로는 이 계층을 계속 확장할 수 있다.

  1. Meta-Meta 문제

업데이트 규칙을 개선하는 규칙 역시 개선 대상이 될 수 있다.

예:

[ U_{t+1}=M_t(U_t,E_t) ]

그리고

[ M_{t+1}=Q_t(M_t,E_t) ]

이 구조를 계속 확장하면 meta-meta-meta hierarchy가 생긴다.

그러나 실제 시스템에서는 무한한 명시적 계층보다, 여러 상위 규칙을 하나의 mutable meta-controller 안에 포함하는 방식이 더 자연스러울 수 있다.

즉 다음과 같이 볼 수 있다.

[ X_t=(\theta_t,S_t,W_t,U_t,A_t,\ldots) ]

그리고 시스템이 자신의 update machinery도 상태의 일부로 포함한다.

  1. Allocation 또는 Control Plane

다중 substrate 시스템에서는 새로운 문제가 생긴다.

경험을 얻었을 때 시스템은 다음을 결정해야 한다.

«이 경험을 어디에 학습시킬 것인가.»

이를 allocation policy "A_t"로 표현할 수 있다.

[ A_t(E_t) \rightarrow {h,\theta,S,W,U} ]

예:

  • 일회성 정보 → memory
  • 반복되는 일반 패턴 → weights
  • search 전략 문제 → scaffold
  • 환경 dynamics 오류 → world model
  • optimizer 문제 → update rule

이 층은 단순 routing보다 훨씬 중요한 의미를 가진다.

사실상 시스템 전체의 학습 자원 배분을 담당한다.

  1. Allocation Policy 자체의 학습

Allocation policy 역시 개선 대상이 될 수 있다.

[ A_{t+1}=V(A_t,E_t,\text{outcomes}) ]

예를 들어 시스템이 처음에는 지나치게 많은 경험을 weight update로 보내다가, 장기간 결과를 보고 특정 종류의 정보는 scaffold에 두는 것이 더 효율적임을 학습할 수 있다.

그러면 시스템은 다음 질문을 학습한다.

  • 무엇을 학습할 것인가
  • 어디에 저장할 것인가
  • 얼마나 빠르게 학습할 것인가
  • 언제 consolidation할 것인가
  • 언제 잊을 것인가
  • 언제 다른 substrate로 이동시킬 것인가

이것은 일종의 learning economics이다.

  1. Fast Learning과 Consolidation

다중 substrate 구조에서는 경험을 먼저 빠른 substrate에 저장한 뒤, 반복되는 경우 느린 substrate로 옮기는 구조가 가능하다.

예:

새 경험 ↓ memory 또는 scaffold에 빠르게 저장 ↓ 반복적 유용성 확인 ↓ weight에 consolidation ↓ 불필요해진 explicit scaffold 제거

이는 fast learning과 slow learning의 분업으로 볼 수 있다.

  1. Self-Model

World model과 별도로 시스템은 자기 자신에 대한 모델을 가질 수 있다.

예:

  • 내 evaluator는 특정 패턴에서 취약하다
  • 내 search policy는 exploit 쪽으로 편향되어 있다
  • 내 memory retrieval이 병목이다
  • 이 문제는 weight learning보다 scaffold update가 적절하다

이를 self-model "W_self"라고 하면 다음 구조가 가능하다.

[ W^{self} \rightarrow \text{diagnosis} \rightarrow A \rightarrow \text{self-modification} ]

이 구조는 RSI와 직접 연결된다.

  1. Counterfactual Self-Modification

World model 또는 self-model이 충분히 발달하면 실제 자기수정 전에 여러 후보를 시뮬레이션할 수 있다.

candidate modification A ↓ simulate consequences ↓ candidate modification B ↓ simulate consequences ↓ compare ↓ actual modification

즉 단순한 self-modification이 아니라 imagined self-modification이 가능해진다.

  1. Recursive Self-Improvement

일반적인 adaptation은 다음과 같다.

[ X_{t+1}=U_t(X_t,E_t) ]

RSI에서는 update machinery 자체가 시스템 상태의 일부가 된다.

[ (X_t,U_t) \rightarrow (X_{t+1},U_{t+1}) ]

그리고 수정된 "U_{t+1}"가 실제 다음 improvement cycle에 사용된다.

따라서 RSI의 핵심은 단순히 시스템이 좋아지는 것이 아니다.

핵심은 다음이다.

«미래의 자기개선을 수행하는 mechanism 자체가 개선되고, 그 개선된 mechanism이 다음 세대의 개선에 실제로 사용된다.»

  1. Structural Recursion과 Effective Recursion

두 개를 구별할 필요가 있다.

Structural Recursion

개선 mechanism이 실제로 수정되고 후속 개선에 다시 사용된다.

Effective Recursion

수정된 mechanism이 실제로 이전보다 더 좋은 successor를 만들어낸다.

따라서 단순히

[ U_0\rightarrow U_1\rightarrow U_2 ]

가 일어났다고 해서 유의미한 RSI가 입증되는 것은 아니다.

중요한 것은 개선 능력 자체가 세대 간에 향상되는지 여부이다.

  1. 현재 RSI와 스캐폴드

현재 많은 RSI 연구에서 foundation model 자체는 고정되어 있다.

대신 다음 요소가 mutable하다.

  • search policy
  • agent code
  • evaluator
  • workflow
  • memory
  • planner
  • orchestration logic

따라서 현재 많은 RSI 시스템은 정확히 말하면 다음에 가깝다.

«stateless 또는 relatively fixed foundation model을 cognition engine으로 사용하고, persistent scaffold가 자기 자신을 수정하는 시스템»

이 관점에서 scaffold는 단순한 보조장치가 아니다.

시스템의 장기적 적응과 recursion을 담당하는 핵심 substrate가 될 수 있다.

  1. 인간 지능과의 기능적 수렴

이러한 기능적 분화는 인간 지능을 직접 복제하려고 해서 나타나는 것이 아닐 수 있다.

오히려 다음과 같은 공통 압력 때문에 독립적으로 비슷한 구조가 나타날 수 있다.

  • 제한된 계산 자원
  • 불완전한 정보
  • 장기간 지속되는 환경
  • 변화하는 환경
  • 여러 시간척도의 학습
  • 기억 비용
  • catastrophic interference
  • 불확실성
  • 장기 planning
  • 사회적 interaction
  • 자기 오류 교정
  • 여러 competing goals

이 압력들은 다음 기능적 분화를 유도할 수 있다.

  • working state
  • long-term memory
  • consolidation
  • attention
  • executive control
  • metacognition
  • world model
  • self-model
  • selective forgetting
  • learning strategy

따라서 인간 지능과 AI 지능이 일부 구조에서 닮아갈 수 있다.

그러나 이는 인간 뇌를 직접 모방한 결과가 아니라 convergent functional organization일 수 있다.

  1. Pressure Replication

이 관점에서 인간 지능은 AI의 설계도라기보다 하나의 해답 사례이다.

보다 근본적인 접근은 다음과 같다.

인간 지능의 architecture를 직접 복제

보다

지능을 형성한 기능적·환경적 압력을 재현

하는 것이다.

즉:

[ \text{shared pressures} \rightarrow \begin{cases} \text{human intelligence}
\text{artificial intelligence} \end{cases} ]

인간과 AI는 substrate와 환경이 다르기 때문에 동일한 구조로 수렴할 필요는 없다.

그러나 비슷한 adaptive problem을 해결하면서 일부 기능적 모듈은 수렴할 수 있다.

  1. 감정 유사 서브시스템

이 논리를 확장하면 감정과 기능적으로 유사한 subsystem의 등장도 미리 배제할 수 없다.

다만 다음은 구별해야 한다.

  • 감정 표현
  • 감정과 기능적으로 유사한 regulatory system
  • 주관적 감정 경험

여기서 관심 대상은 두 번째이다.

복잡한 agent가 여러 subsystem을 동시에 조절해야 한다면, 저차원 global regulatory state를 두는 것이 유용할 수 있다.

예:

[ e_t \rightarrow \begin{cases} \text{attention}
\text{risk tolerance}
\text{exploration}
\text{memory priority}
\text{learning rate}
\text{planning horizon}
\text{resource allocation} \end{cases} ]

예를 들어 높은 불확실성과 반복 실패가 동시에 나타날 때 하나의 global alarm-like state가 여러 subsystem을 동시에 조절할 수 있다.

이런 구조는 기능적으로 인간의 affect system과 닮을 수 있다.

  1. 감정 유사 상태의 진화적 의미

감정 유사 subsystem은 인간 감정을 직접 복제할 필요가 없다.

그것은 다음과 같은 문제를 해결하는 global coordination mechanism으로 등장할 수 있다.

  • 많은 subsystem 간 빠른 coordination
  • 위험 시 행동 regime 전환
  • memory priority 조정
  • exploration/exploitation 전환
  • learning rate 조절
  • irreversible action 억제
  • resource 집중

따라서 인간에게서 나타나는 fear, anger, joy 같은 discrete category와 동일할 필요는 없다.

AI는 자신의 환경적 압력에 맞는 전혀 다른 affect-like state를 가질 수 있다.

  1. 감정 Regulation 자체의 학습

감정 유사 regulatory system 역시 학습 대상이 될 수 있다.

[ e_{t+1}=R_t(e_t,X_t,E_t) ]

그리고

[ R_t\rightarrow R_{t+1} ]

가 가능하다.

즉 시스템은 다음도 학습할 수 있다.

  • 어떤 상황에서 global alarm을 얼마나 크게 걸 것인가
  • 어떤 상태에서는 exploration을 줄일 것인가
  • affect-like signal을 어느 정도 신뢰할 것인가

이 경우 인간의 emotion regulation이나 metacognitive control과 기능적으로 유사한 층이 등장할 수 있다.

  1. 인간 지능 연구에 대한 함의

AI는 인간 지능을 단순히 복제하는 도구가 아니라 지능 일반의 조건을 실험하는 플랫폼이 될 수 있다.

과거에는 주로 다음 질문을 했다.

«인간의 특정 뇌 구조는 무엇을 하는가.»

AI를 통해서는 다음 질문을 직접 실험할 수 있다.

«어떤 환경적·계산적 압력이 주어질 때 어떤 기능적 구조가 필요해지는가.»

이를 통해 인간 지능의 요소를 두 종류로 구분할 가능성이 생긴다.

일반 지능에 가까운 기능

AI에서도 독립적으로 반복 등장하는 구조.

예:

  • working state
  • consolidation
  • executive control
  • world model
  • self-model
  • selective memory
  • meta-learning

인간 특유의 구현

인간의 생물학적·사회적·진화적 조건 때문에 생긴 구조.

AI에서는 필요하지 않을 수 있다.

  1. 전체 아키텍처

가장 일반적인 미래 적응형 AI를 다음과 같이 표현할 수 있다.

[ \mathcal A_t= (h_t,\theta_t,S_t,W_t,U_t,A_t,e_t,\ldots) ]

여기서:

h_t = 빠른 neural / latent state

θ_t = parametric knowledge

S_t = memory, code, policy, workflow, tools

W_t = world model + self-model

U_t = update machinery

A_t = 어떤 substrate를 어떻게 학습시킬지 결정하는 policy

e_t = global regulatory / affect-like state

전체 시스템은 다음과 같이 변화한다.

[ \mathcal A_{t+1}

F_{\mathcal A_t} (\mathcal A_t,E_t) ]

강한 형태에서는 현재 시스템의 일부가 자기 다음 상태를 만드는 transition rule 자체를 수정한다.

  1. 최종 관점

향후 지능 시스템을 다음처럼 보는 것이 유용하다.

«하나의 모델이 학습하는 시스템이 아니라, 서로 다른 시간척도와 표현 형식을 가진 여러 학습 substrate가 결합된 adaptive system.»

그리고 더 강한 단계에서는 다음이 가능하다.

«시스템이 무엇을 학습할지뿐 아니라, 어디에 저장할지, 어떤 속도로 학습할지, 어떤 update rule을 쓸지, 어떤 subsystem을 수정할지, 그 판단 규칙 자체를 어떻게 개선할지도 학습한다.»

이 관점에서는 다음 분야들이 하나의 큰 landscape 안에 들어온다.

  • neural state
  • continual learning
  • memory
  • scaffold learning
  • world models
  • self-models
  • meta-learning
  • learned optimizers
  • self-evolving agents
  • RSI
  • affect-like control
  • open-ended adaptation

따라서 장기적인 상위 개념은 단순한 "LLM", "agent", "world model", "RSI"보다 다음 표현에 더 가깝다.

«multi-substrate, multi-timescale, self-modifying adaptive intelligence»

이 시스템에서 중요한 것은 특정 구성요소의 이름이 아니라 다음 두 질문이다.

«어떤 상태가 지속되는가. 그리고 어떤 상태가 다른 상태의 변화 규칙까지 수정할 수 있는가.»
